# VGG16 질병 탐지 모델

이 폴더는 VGG16 모델을 사용한 어류 질병 탐지를 위한 가중치 파일들을 저장합니다.

## 파일 구조
```
vgg16/
├── README.md          # 이 파일
├── best_model.h5     # 학습된 VGG16 가중치 파일 (질병 탐지용)
├── model_config.json # 모델 아키텍처 설정
└── classes.json      # 탐지할 질병 클래스 정보
```

## 모델 정보
- **목적**: 어류 질병 탐지 (질병 종류 분류)
- **모델**: VGG16 (전이학습)
- **입력**: 어류 이미지
- **출력**: 질병 클래스 + 확률

## 사용 방법
1. 학습된 `best_model.h5` 파일을 이 폴더에 복사
2. Django 앱에서 모델 로드하여 질병 분류 수행
