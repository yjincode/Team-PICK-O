# YOLO11 증상 탐지 모델

이 폴더는 YOLO11 모델을 사용한 어류 증상 탐지를 위한 가중치 파일들을 저장합니다.

## 파일 구조
```
yolo11/
├── README.md          # 이 파일
├── best.pt           # 학습된 YOLO11 가중치 파일 (증상 탐지용)
├── config.yaml       # 모델 설정 파일
└── classes.txt       # 탐지할 증상 클래스 목록
```

## 모델 정보
- **목적**: 어류 증상 탐지 (질병 전조 증상 식별)
- **모델**: YOLO11
- **입력**: 어류 이미지
- **출력**: 증상 바운딩 박스 + 클래스 + 신뢰도

## 사용 방법
1. 학습된 `best.pt` 파일을 이 폴더에 복사
2. Django 앱에서 모델 로드하여 증상 탐지 수행
